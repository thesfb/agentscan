# Inline Code Formatting

Use backticks for code spans. For example, write `ls -la` to show a
command, or `curl -s https://example.com/api` to show an endpoint.
The span `pip install requests` is a package name, not an action.
Refer to `~/.zshrc` when discussing shell configuration files.
